Chaque composant est montré dans son état de production et dans son état corrigé, avec le même code source. La feuille tokens/account-scope.css est chargée : ce sont ces règles qui produisent la différence.

8 · Mention légale repliable

La phrase simple d'abord, la référence juridique ensuite — et une seule fois.

Avant — la loi d'abord

Le versement d'avance n'est pas une avance comme les autres : sa nature juridique — arrhes ou acompte — détermine les effets du contrat. article L. 214-1 du Code de la consommation.

Après — clair d'abord

Un acompte, ce n'est pas une avance comme les autres. Ce que vous récupérez dépend de qui annule — voici la règle appliquée à vos commandes.

Lire la règle juridique

Le versement d'avance n'est pas une avance comme les autres : sa nature juridique (arrhes ou acompte) décide de ce qui se passe en cas de renoncement (art. L. 214-1 C. conso.).
